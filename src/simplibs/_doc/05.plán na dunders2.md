A tedy jako prvn na řadě je tedy tento:

# 1) 🟦 **RepresentationMixin**  
*(popis objektu, reprezentace, stringy)*

Obsahuje:

- **Repr** → `__repr__`
- **Str** → `__str__`
- **Format** → `__format__`
- **Bytes** → `__bytes__`
- **Bool** → `__bool__`

Proč spolu:  
→ Všechny určují, *jak se objekt prezentuje navenek*.

A tedy nejprve co k nim mám za kody v původních dunder mixinech:

    def __repr__(self) -> str:
        return f"{self.__class__.__name__}({self.value!r})"

2)
    def __str__(self) -> str:
        return str(self.value)

3)
    def format(self, pattern: str = None) -> str:
        """
        Zformátuje hodnotu. Pokud není pattern zadán, zkusí ho najít v metadatech.
        Příklad: "+420 {}" pro telefonní číslo.
        """
        # Hledáme masku v metadatech (pokud ji tam v budoucnu přidáme)
        mask = pattern or getattr(self.meta, 'mask', None)

        if mask and isinstance(self.value, (str, int, float)):
            # Rozhodnout se za potřebuji zde try except blok a nebo je zbytečný?
            # try:
            #     return mask.format(self.value)
            # except Exception:
            #     # Pokud formátování selže, vrátíme prostě str(self.value)
            #     return str(self.value)
            return mask.format(self.value)

        return str(self.value)

    def __format__(self, format_spec: str) -> str:
        """Podpora pro f-stringy: f"{obj:maska}" """
        return self.format(format_spec)

4)
    def __bytes__(self):
        try:
            return bytes(self.value)
        except (TypeError, ValueError):
            # runtime neakceptuje NotImplemented z conversion metod.
            # Musí buď vrátit hodnotu, nebo vyhodit TypeError.
            raise TypeError(f"Nelze převést {self.__class__.__name__} na int: {e}")

5)
    def __bool__(self) -> bool:
        return bool(self.value)

A tedy to první co ptřebuje zhodnotit zda jsou jednotlivé prvk správně nastavené na aktuální systém - a tedy to nejhlavnější, zda zde mít repr a str, když už jej definujeme na základní třídě InstanceBase:

    #--- Definice __repr__ (reprezentačního řetězce objektu) ---#
    # (univerzální definice společná všem potomkům)
    def __repr__(self) -> str:
        """
        Unifikovaná technická reprezentace pro všechny prvky systému Simple.
        Nenaznačuje možnost předávání parametrů do initu, ale transparentně
        ukazuje typ, původ, stav a paměťové ID.
        """
        class_name  = self.meta.class_name
        blueprint   = f"blueprint='{self.meta.blueprint_path}'"
        state       = f"value={self._value!r}" if hasattr(self, "_value") else ""
        hex_id      = f"id={hex(id(self))}"

        return f"<{class_name} {blueprint} {state} {hex_id}>"

    #--- Definice __str__ (řetězec reprezentující jméno třídy) ---#
    # (univerzální definice společná všem potomkům)
    def __str__(self) -> str:
        """
        Uživatelská reprezentace.
        Příklad: Auto
        """
        return self.meta.class_name

A tedy jde o to, zda tato definice co máme na InstanceBase je lepší a ideální a tedy v mixinu už pak nemá cenu to přepisovat a nebo zda naopak má cenu mít v tom mixinu i repr a str.
